ადგილობრივი `ertad_test`, `127.0.0.1:55432`, მომხმარებელი `ertad`, PostgreSQL **16.15**, `datcollate=C`, `datctype=C`. შემოწმება შესრულდა `BEGIN READ ONLY`-ში, JSON პარამეტრებიდან, ცხრილების შექმნის ან ცვლილების გარეშე. 87-ვე pattern შემოწმდა თავისი მშობლის ყველა ექსპორტირებულ სათაურზე: **72,209 წყვილი**, JS-ში **8,143 დადებითი** დამთხვევა. გაზომილი სრული შედარების დრო დაახლოებით 3.3 წამია; ეს არ არის production API-ის latency-ის ტესტი.

მოთხოვნილი SQL გამოხატულება:

```sql
SELECT lower(normalize(t.title, NFKC)) ~ r.pattern
FROM jsonb_to_recordset($1::jsonb) AS t(line int, title text, category text)
JOIN jsonb_to_recordset($2::jsonb) AS r(id text, category text, pattern text)

```

## UX — ზუსტი დავალება შემდეგი ნაკადისთვის
