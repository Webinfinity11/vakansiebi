# UI/UX გადამუშავება — 10 სექტემბერი, 2026

## კრიტიკა და გადაწყვეტილებები

წინა ვერსიაში მწვანე ერთდროულად გამოიყენებოდა ფონისთვის, სათაურებისთვის, მეტამონაცემებისა და მოქმედებებისთვის. პირველი ვაკანსია 1440×1000 ეკრანზე 641px-ზე იწყებოდა; შესავალი და განმეორებითი დამხმარე ტექსტები კონკურენციას უწევდა რეალურ განცხადებებს.

ახალი ვერსია იყენებს მუქ ტექსტს, თეთრ ბარათებს, ნეიტრალურ ფონსა და ლურჯ მოქმედებებს. შემოკლებულია შესავალი, კომპაქტურია წყაროების სტატისტიკა. დესკტოპზე აღარ მეორდება ნავიგაციის „ჩემი სივრცე“ ღილაკი, ხოლო ძიების შენახვა ჩნდება შესაბამისი პირობების არჩევისას. მობილურზე ეს სივრცე ხელმისაწვდომია შედეგების ხელსაწყოებში.

ბარათზე თვალსაჩინოა კომპანია, პოზიცია და ანაზღაურება თავისი პერიოდით. პირველწყარო რჩება ბარათზე; შემოწმების თარიღი და სრული წარმოშობის ინფორმაცია — დეტალებში. გაიზარდა სათაურებისა და პირობების ტექსტი. რეალური ლოგოები და ნეიტრალური ჩანაცვლება შენარჩუნებულია.

მობილურზე გასწორდა ძველი CSS წესების კონფლიქტი, რომელიც ქალაქის არჩევასა და ძიების ღილაკს ერთ უჯრაში ათავსებდა. სწრაფი არჩევანის ზოლი ჰორიზონტალურად გადაადგილდება; ფილტრების მონახაზი კვლავ მხოლოდ „გამოყენებით“ ინახება. შედეგების ცოცხალი შეტყობინება ეკრანის წამკითხველისთვის შენარჩუნებულია.

## კვლევის საფუძველი

- [NN/g — Visual Hierarchy](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/): ზომა, კონტრასტი და ფერი გამოყოფს ინფორმაციის პრიორიტეტებს. ჩვენი გადაწყვეტილებაა პოზიციისა და ძიების მოქმედების გამოკვეთა.
- [NN/g — Layer-Cake Scanning](https://www.nngroup.com/articles/layer-cake-pattern-scanning/): მკაფიო სათაურები სწრაფ დათვალიერებას უწყობს ხელს. ერთგვაროვანი ბარათები და უფრო მკაფიო პოზიციის სათაურები ამ პრინციპს ეყრდნობა.
- [NN/g — Aesthetic-Usability Effect](https://www.nngroup.com/articles/aesthetic-usability-effect/): ვიზუალური ხარისხი აღქმულ მოხერხებულობაზე მოქმედებს. ეს არ ამტკიცებს, რომ კონკრეტულად ლურჯი ფერი ჩვენს საიტზე დაბრუნებას გაზრდის.

ეს არის კვლევაზე დაფუძნებული დიზაინის გადაწყვეტილება და ბრაუზერით შემოწმებული განხორციელება; მომხმარებელთა ინტერვიუები ან A/B ტესტი არ ჩატარებულა. ახალი ფონტები, გამოსახულებები, ბიბლიოთეკები ან ქსელური მოთხოვნები არ დამატებულა.

## შემოწმება

1440×1000 ლოკალურ ხედში პირველი ბარათი 476px-ზე იწყება — 165px-ით მაღლა. მობილურზე 390×844 პირველი ბარათი 595px-ზეა. ეს განლაგების გაზომვაა და არა მომხმარებლის ქცევის მაჩვენებელი.

შემოწმებულია TypeScript, lint და production build; ბრაუზერში — დღიური ანაზღაურების ფილტრი, ძიების გაზიარება/აღდგენა, შეცდომით აკრეფილი სიტყვის შეთავაზება, მობილურის ფილტრების გამოყენება/გაუქმება/გასუფთავება.

დამატებით შემოწმებულია 320, 390, 768, 1024 და 1440px სიგანეები — ჰორიზონტალური გადავსების გარეშე; ქალაქის არჩევა/კლავიატურით დახურვა, ვაკანსიის შენახვა/მოხსნა და დეტალების გახსნა. ამ სცენარებში JavaScript შეცდომები არ დაფიქსირდა.
